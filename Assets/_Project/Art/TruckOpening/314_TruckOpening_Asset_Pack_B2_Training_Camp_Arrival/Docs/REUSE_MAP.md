# B1 reuse map

B2 is designed to sit beside the existing `314_TruckOpening_Asset_Pack_B` folder. Do not copy or rename the following B1 files inside B2.

| Sequence / object | Reused B1 asset | B2 addition |
|---|---|---|
| Shared dawn sky | `Background/B01_sky_dawn_1920x1080.png` | None |
| Far landscape | `Background/B02_mountains_far.png` | `Background/B2_04_training_yard_midground.png` in the arrival zone |
| Residential section | `Background/B03_village_mid.png` | None |
| Rice-field section | `Background/B04_rice_field_near.png` | None |
| Forest approach | `Background/B07_forest_transition.png` | Gate assembly begins after this section |
| Continuous road | `Ground/B05_road_dirt_loop.png` | `Ground/B2_06_truck_stop_pad_overlay.png` at the stop point |
| Optional near foliage | `Foreground/B06_foreground_bamboo_grass.png` | None |
| Truck body | `Vehicle/B08_truck_body_no_wheels.png` | None |
| Front wheel | `Vehicle/B09_wheel_front.png` | None |
| Rear wheel | `Vehicle/B10_wheel_rear.png` | None |
| Seated recruits | `Vehicle/B11_recruits_row.png` | Standing/disembarking poses in B2 |
| Driver | `Vehicle/B12_driver.png` | None |
| Moving dust | `VFX/B15_dust_sheet_4x2.png` or individual `VFX/Dust/*.png` | Disable/fade at the stop point |
| Blank sign | `Props/B16_training_sign_blank.png` | Still available for other road/training labels; the gate now uses B2 split signage |

The three B2 previews intentionally assemble these B1 assets with the new B2 layers. They are the compatibility check for the shared art direction and scale.
